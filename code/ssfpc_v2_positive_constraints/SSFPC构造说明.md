# SSFPC 构造说明（v2 正约束特例版）

本文档给出本项目 SSFPC 实现的完整推导链：从 Wang et al. (2022, IEEE TFS)
的原始模型出发，删除负约束分支（简化式 6），重新推导全部公式。
写作口径：**"SSFPC 的正约束特例"（positive-constraint specialization）**，
非新算法；创新点在约束的自动生成（demographic 画像 → Gower 相似度 → s_pq）
与电力零售场景落地。

## 1. 模型：简化式 (6) 与目标函数

**定义（正约束特例）**：模糊成对约束 s_pq ∈ (0,1] 度量样本 p, q 的隶属度向量
u_p, u_q 应接近的程度；0（不出现在约束集中）表示未知。

**简化式 (6)**：

    C(u_p, u_q) = ½·s_pq·‖u_p − u_q‖²      (s_pq > 0)

（负分支 −s·u_pᵀu_q 整支删除。原文设负约束用内积而非 L2，是为避免相异对被
逼向 one-hot 角点、保留模糊性；本场景无负约束，该设计不涉及。）

**目标函数（式 5，γ=2，α=0）**：

    min_{{u_i},{c_j}}  J = Σ_i Σ_j u_ij²·‖x_i − c_j‖²
                         + (β/2)·Σ_{(p,q)∈S} s_pq·‖u_p − u_q‖²
    s.t.  Σ_j u_ij = 1,  u_ij ≥ 0

第一项：原型聚合（标准 FCM，γ=2）；第二项：约束引导，拉动相似样本的
隶属度向量彼此接近，同时**保留模糊特性**（最小化 L2 而非最大化内积）。

## 2. MEM 求解框架（Algorithm 1）

交替更新直至收敛：

**E 步（式 13，中心更新）**：固定 U，

    c_j = Σ_i u_ij²·x_i / Σ_i u_ij²

（α=0；实现上分母 clamp_min(1e-12) 作空簇防护。）

**M 步（隶属度更新）**：固定 {c_j}，两类样本分流——

- 无约束样本（式 14 闭式）：u_ij = (1/d_ij) / Σ_j'(1/d_ij')，d_ij = ‖x_i−c_j‖²；
- 有约束样本：按约束图连通块分解（式 15 的依据："associated directly or
  indirectly"，实现为并查集），逐块解 QP，见 §3。

**收敛性**：每步均为精确最小化、J 有下界 0 ⇒ J 单调不增且收敛
（原文定理 III.1 的论证直接适用；正约束特例下每步还是凸问题全局解，
论证更强）。v1 实验已数值验证：160 步 0 次上升。

## 3. 块子问题的 QP 构造（式 15 的矩阵化）

对一个连通块，r 个样本、簇数 k、块内约束边集 E（权重 s_pq>0），
d_ij = ‖x_i − c_j‖²。块子问题：

    min  Σ_iΣ_j d_ij·u_ij² + (β/2)·Σ_{(p,q)∈E} s_pq·‖u_p − u_q‖²
    s.t. 行和=1, u≥0

**变量排布**：按簇分块 u = [u_·1; …; u_·k] ∈ R^{rk}。

**拉普拉斯恒等式**：对第 j 簇，令 u_·j = (u_1j,…,u_rj)ᵀ，

    Σ_{(p,q)∈E} s_pq·(u_pj − u_qj)² = u_·jᵀ L u_·j

其中 **L = Λ − W** 为块内约束图的加权图拉普拉斯：W 为对称邻接矩阵
（W_pq = s_pq），Λ = diag(λ_i)，λ_i = Σ_q s_iq（加权度）。

**QP 标准形**：

    min  ½·uᵀ P u ,   s.t.  A u = 1_r,  u ≥ 0

    P = blkdiag( P_1, …, P_k ),   P_j = 2·diag(d_·j) + β·L

系数 2 的来源：½uᵀPu 的约定下，P_j 取 2·diag(d) 使目标精确等于
Σd·u² + (β/2)Σs‖Δu‖²（论文式 5/15 口径）。
**注意：若取 P_j = diag(d) + β·L，β 的实际效力是论文口径的 2 倍
（v1 曾犯此错，v2 已修正）。**

**约束矩阵**：A ∈ {0,1}^{r×rk}，第 i 行在第 i, i+r, …, i+(k−1)r 列为 1；
非负界以区间形式并入（OSQP 的 l/u 形式）。

**与论文式 (18)(19) 的等价性**：论文按样本分块，
D_ii = diag(d_i·) + (β/2)(Σ_{s_ij>0} s_ij)·I，D_ij = −(β/2)s_ij·I。
将 (15) 展开并与拉普拉斯恒等式对照：距离项 ↔ diag(d)；
平方项 (β/2)Σs(‖u_p‖²+‖u_q‖²) ↔ β·Λ；交叉项 −β·s·u_pᵀu_q ↔ −β·W。
二者是同一二次型的置换相似变换，仅存在全局因子 2 的写法约定差异
（论文 uᵀDu 约定 vs 本实现 ½uᵀPu 约定，已通过对角系数 ×2 消除）。
论文式 (15) 中交叉项的 u_p^{(t)} 上标为排版笔误（若为线性化则与
式 (19)、Lemma III.1、Algorithm 2 及官方代码的非对角填充全部矛盾）。

## 4. 正定性定理（Lemma III.1 的正约束特例强化）

**定理**：s_pq ≥ 0 且 d_ij > 0 时，P 严格正定。

**证明**：对任意 u_·j，u_·jᵀ(βL)u_·j = β·Σ s_pq(u_pj−u_qj)² ≥ 0（L 半正定）；
2·diag(d_·j) 各对角元严格为正 ⇒ P_j = 2·diag(d_·j) + βL 严格正定；
块对角保正定性，故 P 严格正定。□

**推论（Algorithm 2 塌缩）**：P 严格正定 ⇒ 块子问题为凸 QP，存在唯一全局
最优解，任意凸 QP 求解器一次求解即得。原文 Algorithm 2 的 BᵀDB 缩减检查、
DBCD 迭代、顶点遍历三个不定分支在本特例下**永不触发**，全部删除。
（原文这些分支为负约束服务：负边代价 −s·u_pᵀu_q 是纯双线性项、无对角
补偿，可能使 D 不定；式 18"对角只累加正约束"的不对称设计正是为了保证
DBCD 每个样本级子问题恒凸。）

**数值验证**：实现中启动时对每块 L 计算最小特征值（eigsh, which="SA"），
λ_min > −1e−8 方放行，结果记入 run_meta.json["pd_check"]。

## 5. 求解器与工程要点

- 求解器：OSQP（ADMM 一阶法），CPU 稀疏；精度 1e−6 + polish。
  最大连通块 1,820 户 × 5 簇 = 9,100 维，稀疏 ADMM 远优于稠密内点法。
- 热启动：第 t+1 轮用第 t 轮的块解 warm start。
- 距离/中心/闭式更新：PyTorch CUDA（RTX 4060）。
- 边界：d_ij=0（样本恰在中心）经 clamp_min(1e−12) 处理，与官方
  "d<eps 硬指派"等价意义下的安全近似。

## 6. 负约束扩展（future work，当前不实现）

若未来需要表达"两户明确不像"（s<0，软 cannot-link）：
① 矩阵构造必须改用式 (18)(19) 的不对称形式（负边只进非对角，
**不能**塞进拉普拉斯，否则会引入目标函数中不存在的平方项）；
② 求解器换 Algorithm 2 完整框架（BᵀDB 检查 + DBCD）；
③ 不定问题 DBCD 仅保证驻点，不保证全局最优。
