# ssfpc_v1_初版

SSFPC（Wang et al. 2022, IEEE TFS）主循环的第一个可运行版本。
**此版本冻结，仅作基线与复现对照，不再修改。**

## 这个版本干了什么

- 输入：`data/output/features_std.npy`（6,031 户 × 5 维标准化负荷行为特征，
  Luo 2019 Table I 口径，由 `data/load_features.py` 生成）+
  `code/dispose/output/constraints_gower.parquet`（54,473 对 Gower 正约束，
  s∈[0,1]，Top-K(10) 对称截断，由 `code/dispose/similarity.py` 生成）。
- 算法：MEM 主循环（α=0）。E 步式 (13) 中心更新；M 步无约束样本走闭式，
  有约束样本按约束图连通块（22 块，最大 1,820 户）逐块解凸 QP
  （OSQP，稀疏 ADMM，热启动）。
- QP 矩阵构造：按簇分块 H = blkdiag_j(diag(d_·j) + β·L)，L 为块内加权图
  拉普拉斯。**自推实现**，后与官方 MATLAB 代码（`code/reference/FDC-main`）
  和论文式 (15)(18)(19) 逐项核对，确认在 s≥0 时数学等价。
- 已完成两次验证运行（输出在 `output/`，覆盖式保存，当前为 β=0.1 那次）：
  - β=0（纯 FCM 基线）：200 轮，17.9s，obj 8019.17→2392.14 单调降，
    簇规模 [2040, 102, 561, 2071, 1257]；
  - β=0.1：159 轮收敛，107.9s，obj=3454.04，簇规模 [1821, 126, 665, 2106, 1313]；
  - 四项验证全过：目标函数 160 步 0 次上升；约束对 s 与隶属度距离相关 −0.156；
    硬标签一致率 43.9%（5 簇随机基线 37.8%）；隶属度行和恰为 1。

## 已知问题（v2 已修）

1. **因子 2 不一致**：QP 实际优化 ½Σd·u² + (β/2)Σs‖Δu‖²（距离项系数 ½），
   论文式 (5) 口径为 Σd·u² + (β/2)Σs‖Δu‖²（距离项系数 1）。
   即 **v1 的 β 实际是论文口径的 2 倍**：v1 β=0.1 ≈ 论文 β=0.2。
   且 objective.csv 记录的式 (5) 与 QP 实际优化量不一致。
2. 无运行时正定性数值验证（仅依赖构造论证）。
3. 随机初始化 U、收敛判据 ‖ΔU‖<1e-6、无空簇处理——与官方实现
   （初始硬标签 + PNNG、中心变化判据、删簇重启）不同，属实现自由度高但
   已验证可收敛的选择。

## 与官方code/论文的偏差备忘

- 不采用官方代码私加的 m/|S| 归一化因子（论文式 (18)(19) 无此项）；
- 只实现 s≥0 正约束分支（负约束 → 不定 QP → DBCD，整条链路不涉及）；
- 详细对照记录见会话归档与 `code/ssfpc_v2_positive_constraints/SSFPC构造说明.md`。

## 运行方式（项目根目录，yolo 环境）

```bash
export POLARS_SKIP_CPU_CHECK=1   # Git Bash 下必须
python code/ssfpc_v1_initial/ssfpc.py
```

注意：脚本内路径相对项目根推导（`parents[2]`），移动本文件夹会失效。
